五、技术栈总览
========================================

  前端框架:     Java Swing (JDK 1.8) + 自定义组件库
  后端语言:     Java 8
  数据库:       Oracle 26ai Free (11张表)
  连接方式:     JDBC (ojdbc8 thin driver)
  构建工具:     Apache Maven (Shade Plugin Fat JAR)
  邮件服务:     JavaMail 1.6.2 (SMTP SSL)
  AI集成:       Ollama REST API (本地LLM, qwen2.5)
  OCR支持:      Tesseract / Cloud API / Demo Mode
  版本控制:     Git / GitHub
  设计模式:     MVC三层 + RBAC权限 + 状态机 + Observer(主题监听)
