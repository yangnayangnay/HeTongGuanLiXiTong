## 第一章 系统简介

### 1.1 系统是什么？

合同管理系统是一套面向企业的合同全生命周期管理软件。它帮助企业管理从合同**起草** → **会签** → **定稿** → **审批** → **签订**的全部流程，并提供完善的**权限控制**和**操作审计**功能。

### 1.2 适用人群

| 角色 | 适用场景 |
|------|----------|
| **管理员** | 管理用户账号、分配角色权限、查看系统日志 |
| **合同操作员** | 起草新合同、定稿最终合同文本 |
| **会签人员** | 对分配给自己的合同进行会签审阅 |
| **审批人员** | 对定稿后的合同进行审批决策 |
| **签订人员** | 对审批通过的合同进行正式签订 |

## 第二章 环境准备

### 2.1 硬件要求

| 配置 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 1 GHz以上 | 2 GHz以上 |
| 内存 | 2 GB | 4 GB及以上 |
| 硬盘 | 500 MB可用空间（含Oracle） | 1 GB及以上 |
|显示器 | 1280×720分辨率 | 1920×1080分辨率 |

### 2.2 软件要求

| 软件 | 版本要求 | 获取方式 |
|------|----------|----------|
| JDK | 1.8 或更高 | [Oracle官网](https://www.oracle.com/java/technologies/downloads/) |
| Oracle Database | 26ai Free (或19c+) | [Oracle官网免费下载](https://www.oracle.com/database/technologies/appdev/xe.html) |
| IDE（可选） | IntelliJ IDEA 2020+ | [JetBrains官网](https://www.jetbrains.com/idea/download/) |

### 2.3 安装JDK

1. 下载JDK安装包
2. 运行安装程序，按向导完成安装
3. 配置环境变量：
   - `JAVA_HOME` = JDK安装目录（如 `C:\Program Files\Java\jdk1.8.0_xx`）
   - 在 `Path` 中追加 `%JAVA_HOME%\bin`
4. 打开命令提示符，输入 `java -version` 验证安装成功

### 2.4 安装Oracle数据库

1. 下载Oracle Database 26ai Free（或其他版本）
2. 运行安装程序，按向导完成安装
3. 记住安装时设置的：
   - **全局数据库名**（通常为 `FREEPDB1` 或 `freepdb1`）
   - **端口**（默认 `1521`）
   - **系统用户密码**

### 2.5 配置start.bat启动脚本

项目中已提供 `doc/start.bat` 用于快速启动Oracle数据库。如果您的Oracle安装路径不同，请修改此文件中的路径。

## 第六章 常见问题

### Q1: 程序启动时提示"未连接到数据库"怎么办？

**A:** 这是正常的。点击 **"是"** 按钮，程序会自动帮你启动数据库。或者你可以先手动双击运行 `doc\start.bat`，等数据库启动后再运行程序。

### Q2: 启动画面一直停在"正在等待数据库启动..."？

**A:** 这说明Oracle数据库还没有完全就绪。请耐心等待（最长5分钟）。如果超过5分钟，请检查：
- Oracle服务是否已在运行（查看任务管理器中的oracle进程）
- 端口1521是否被占用
- start.bat中的配置是否正确

### Q3: 注册后为什么登录不了？

**A:** 本系统采用了**审核机制**。新用户注册后状态为"待审核"，需要管理员在 **「用户管理」→「待审核用户」** 区域中点击 **「通过」** 后才能登录。

### Q4: 我不是管理员，看不到某些菜单怎么办？

**A:** 这是正常的权限控制。左侧导航栏只显示你拥有权限的功能。如果你需要更多权限，请联系管理员为你分配相应的角色。

### Q5: 分配合同时某个人不出现在列表中？

**A:** 分配合同的备选列表是**按权限过滤**的：
- 会签列表只显示有"会签权限"的用户
- 审批列表只显示有"审批权限"的用户
- 签订列表只显示有"签订权限"的用户

请让管理员先给该用户分配对应的角色和权限。

### Q6: 为什么我看不到合同的详细内容？

**A:** 为了保护信息安全，**只有管理员和合同起草人**可以查看完整的合同正文。其他用户只能看到合同的基本信息。这是系统的内容权限控制机制。

### Q7: 合同结束时间怎么调整最方便？

**A:** 起草合同界面提供了**快捷调整按钮**：
- 结束时间输入框左边有两个减号按钮：**-半年**、**-一年**
- 右边有两个加号按钮：**+半年**、**+一年**
- 点击即可快速调整，而且系统保证不会调到开始时间之前

### Q8: 如何修改自己的密码？

**A:** 目前可以通过 **「用户管理」→ 选中自己 → 「修改」** 来修改密码（管理员操作）。未来版本将增加个人中心自助修改功能。

### Q9: admin账户可以被删除吗？

**A:** **不可以**。系统内置的admin账户受保护，删除操作会被阻止。这是为了防止系统中没有任何管理员的情况发生。
