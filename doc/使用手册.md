## 第一章 系统简介

### 1.1 系统是什么？

合同管理系统是一套基于B/S架构的企业合同全生命周期管理软件。用户通过浏览器访问系统，实现合同**起草** → **分配** → **会签** → **定稿** → **审批** → **签订**的全部流程，并提供完善的**权限控制**、**电子签名**、**AI智能起草**、**邮件通知**和**操作审计**功能。

### 1.2 适用人群

| 角色 | 适用场景 |
|------|----------|
| **管理员** | 管理用户账号、分配角色权限、查看系统日志、系统设置 |
| **合同操作员** | 起草新合同、定稿最终合同文本 |
| **会签人员** | 对分配给自己的合同进行会签审阅 |
| **审批人员** | 对定稿后的合同进行审批决策（可否决退回定稿） |
| **签订人员** | 对审批通过的合同进行正式签订（含电子签名） |

## 第二章 环境准备

### 2.1 硬件要求

| 配置 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 1 GHz以上 | 2 GHz以上 |
| 内存 | 2 GB | 4 GB及以上 |
| 硬盘 | 500 MB可用空间（含Oracle） | 1 GB及以上 |
| 显示器 | 1280×720分辨率 | 1920×1080分辨率 |

### 2.2 软件要求

| 软件 | 版本要求 | 获取方式 |
|------|----------|----------|
| JDK | 1.8 或更高 | [Oracle官网](https://www.oracle.com/java/technologies/downloads/) |
| Oracle Database | 26ai Free (或19c+) | [Oracle官网免费下载](https://www.oracle.com/database/technologies/appdev/xe.html) |
| Maven | 3.x | [Maven官网](https://maven.apache.org/download.cgi) |
| 浏览器 | Chrome/Firefox/Edge 最新版 | 系统自带或官网下载 |
| Ollama（可选） | 最新版 + qwen2:7b模型 | [Ollama官网](https://ollama.ai) |

### 2.3 安装JDK

1. 下载JDK安装包
2. 运行安装程序，按向导完成安装
3. 配置环境变量：
   - `JAVA_HOME` = JDK安装目录（如 `C:\Program Files\Java\jdk1.8.0_xx`）
   - 在 `Path` 中追加 `%JAVA_HOME%\bin`
4. 打开命令提示符，输入 `java -version` 验证安装成功

### 2.4 安装Oracle数据库

1. 下载Oracle Database 26ai Free（或其他版本）
2. 运行安装程序，按向导完成安装
3. 记住安装时设置的：
   - **全局数据库名**（通常为 `FREEPDB1` 或 `freepdb1`）
   - **端口**（默认 `1521`）
   - **系统用户密码**

### 2.5 安装Ollama（可选，用于AI功能）

1. 访问 [Ollama官网](https://ollama.ai) 下载并安装
2. 安装完成后，在命令行执行：
   ```bash
   ollama pull qwen2:7b
   ```
3. 等待模型下载完成，Ollama默认运行在端口11434

## 第三章 快速启动

### 3.1 启动步骤（仅需4步）

```
第1步：启动数据库（如未启动）
       双击运行 doc\start.bat
       等待提示"数据库已就绪"

第2步：启动应用
       用IntelliJ IDEA打开项目
       运行 ContractApplication.java 的 main 方法

第3步：等待启动完成
       控制台显示 "Started ContractApplication" 即表示启动成功

第4步：打开浏览器
       访问 http://localhost:8080
       进入登录页面
```

### 3.2 启动说明

Spring Boot应用启动后会自动完成以下步骤：

| 步骤 | 说明 |
|------|------|
| 1 | 连接Oracle数据库 |
| 2 | 检查数据库表结构是否存在 |
| 3 | 首次运行时自动创建表并初始化数据 |
| 4 | 启动内嵌Tomcat服务器（端口8080） |
| 5 | 浏览器访问 http://localhost:8080 即可使用 |

### 3.3 如果数据库没启动怎么办？

如果Oracle数据库未运行，Spring Boot启动时会报数据库连接错误。请按以下步骤操作：

1. 双击运行 `doc\start.bat` 启动数据库
2. 等待数据库完全就绪（约30秒~2分钟）
3. 重新运行 `ContractApplication.java`

### 3.4 默认账号

| 用户名 | 密码 | 角色 | 说明 |
|--------|------|------|------|
| `admin` | `admin123` | 管理员 | 超级管理员，拥有所有权限 |

> **重要提示**：请登录后立即修改admin的密码！

<!-- 【图片预留位置：注册页面截图】 -->

### 4.2 合同操作

#### 4.2.1 起草合同

适用角色：**合同操作员**、**管理员**

<!-- 【图片预留位置：起草合同页面截图】 -->
<!-- 请在此处插入起草合同页面的实际截图，标注各输入区域 -->

**操作步骤：**

1. 在侧边导航栏点击 **「起草合同」**
2. 填写表单：

| 字段 | 是否必填 | 说明 | 默认值 |
|------|----------|------|--------|
| 合同名称 | 必填 | 合同的标题 | 手动输入 |
| 客户 | 必选 | 下拉选择客户 | 需先在客户管理中添加 |
| 开始时间 | 选填 | 合同生效日期 | **默认今天** |
| 结束时间 | 选填 | 合同到期日期 | **默认1年后** |
| 合同内容 | 必填 | 合同正文 | 大文本框输入 |

3. **日期智能校验**：结束时间不能早于开始时间，系统会自动修正
4. 点击 **「提交起草」** 按钮
5. 成功后会显示生成的**合同编号**（格式：`HT` + 年月日 + 序号，如 `HT202606080001`）

> **提示**：也可以使用AI智能起草功能，详见[4.5.1 AI智能起草](#451-ai智能起草)

#### 4.2.2 分配合同

适用角色：仅 **管理员**

<!-- 【图片预留位置：分配合同页面截图】 -->
<!-- 请在此处插入分配合同页面的实际截图 -->

**操作步骤：**

1. 在侧边导航栏点击 **「分配合同」**（仅管理员可见）
2. 上方表格列出所有状态为"起草"的合同，**选中要分配的合同**
3. 下方有三列人员选择列表：

| 列表 | 说明 | 列表中的人 |
|------|------|------------|
| 会签人员 | 负责会签审阅 | 只有拥有**会签权限**的用户 |
| 审批人员 | 负责审批决策 | 只有拥有**审批权限**的用户 |
| 签订人员 | 负责正式签订 | 只有拥有**签订权限**的用户 |

> **注意**：每列可以多选。三列都必须至少选一个人。

4. 点击 **「确认分配」** 完成
5. 分配完成后，系统会自动发送邮件通知相关人员

#### 4.2.3 会签合同

适用角色：**会签人员**、**管理员**

<!-- 【图片预留位置：会签合同页面截图】 -->
<!-- 请在此处插入会签合同页面的实际截图 -->

**操作步骤：**

1. 点击 **「会签合同」**
2. 上方表格显示**分配给您**的待会签合同
3. 选中一个合同，下方显示：
   - **合同内容**：只读查看
   - **历史意见**：可查看之前所有人的操作意见
   - **会签意见**：填写您的审阅意见
4. 点击 **「确认会签」** 提交

> 当所有会签人员都完成会签后，合同自动进入"待定稿"状态。

#### 4.2.4 定稿合同

适用角色：**合同操作员**、**管理员**

<!-- 【图片预留位置：定稿合同页面截图】 -->
<!-- 请在此处插入定稿合同页面的实际截图 -->

**操作步骤：**

1. 点击 **「定稿合同」**
2. 上方表格显示**您起草的**且已完成会签的合同
3. **查看会签意见**：中间区域显示所有会签人员的意见
4. **查看历史意见**：可查看每步操作的历史意见
5. **修改合同内容**：在编辑区根据会签意见修改最终文本
6. 点击 **「确认定稿」** 提交

> **审批否决退回**：如果合同在审批阶段被否决，会退回定稿阶段，此时定稿页面会显示审批否决的意见，起草人可根据意见修改后重新定稿。

#### 4.2.5 审批合同

适用角色：**审批人员**、**管理员**

<!-- 【图片预留位置：审批合同页面截图】 -->
<!-- 请在此处插入审批合同页面的实际截图 -->

**操作步骤：**

1. 点击 **「审批合同」**
2. 上方表格显示**分配给您**的待审批合同
3. 选中合同，查看内容和历史意见
4. 选择操作：
   - **「审批通过」**：同意该合同
   - **「审批否决」**：否决该合同，合同退回定稿阶段
5. 可选填写审批意见

> **重要说明**：
> - 审批否决后，合同不会终止，而是退回到定稿阶段
> - 否决意见会保留，起草人可在定稿时查看
> - 起草人修改后可重新定稿，再次进入审批流程

#### 4.2.6 签订合同

适用角色：**签订人员**、**管理员**

<!-- 【图片预留位置：签订合同页面截图】 -->
<!-- 请在此处插入签订合同页面的实际截图 -->

**操作步骤：**

1. 点击 **「签订合同」**
2. 上方表格显示**分配给您**的待签订合同（已通过审批）
3. 选中合同，确认内容无误
4. **电子签名**：在签名区域使用鼠标/触摸板手写签名
5. 点击 **「确认签订」** 完成

> 签订完成后，合同的全生命周期流程到此结束。

### 4.3 信息查询

#### 4.3.1 合同查询

<!-- 【图片预留位置：合同查询页面截图】 -->
<!-- 请在此处插入合同查询页面的实际截图 -->

**操作步骤：**

1. 点击 **「合同查询」**
2. **搜索方式**：
   - **关键字搜索**：在搜索框输入合同名称关键字
   - **时间范围筛选**：选择起止日期范围
   - **进度筛选**：按合同进度状态筛选
3. 点击 **「查询」** 执行搜索
4. **查看详情**：点击表格中的任意一行，下方**详情区**显示完整信息

**权限说明：**

| 用户类型 | 能看到的内容 |
|----------|-------------|

#### 4.3.2 流程查询

1. 点击 **「流程查询」**
2. 可以按**时间范围**和**状态**筛选合同
3. 点击某个合同，查看其完整的**流转历史记录**（谁、什么时候、做了什么操作、意见内容）

### 4.5 智能辅助功能

#### 4.5.1 AI智能起草

<!-- 【图片预留位置：AI智能起草截图】 -->
<!-- 请在此处插入AI智能起草功能的截图 -->

1. 在起草合同页面，点击 **「AI智能起草」** 按钮
2. 系统基于Ollama本地AI（qwen2:7b模型）自动生成合同内容
3. AI采用模板填充模式，根据合同名称和客户信息生成合同正文
4. 生成的内容可手动修改调整

> **前提条件**：需要安装并运行Ollama，且已下载qwen2:7b模型。如未配置，可在系统设置中配置AI参数。

#### 4.5.2 电子签名

<!-- 【图片预留位置：电子签名截图】 -->
<!-- 请在此处插入电子签名Canvas手写区域的截图 -->

1. 在签订合同页面，找到**电子签名区域**
2. 使用鼠标或触摸板在Canvas画布上手写签名
3. 签名会以图片形式插入到合同中
4. 可点击 **「清除签名」** 重新书写

> 电子签名设置可在 **「系统设置」** 中配置。

#### 4.5.3 邮件通知

系统在以下场景会自动发送邮件通知：

| 场景 | 通知对象 | 邮件内容 |
|------|----------|----------|
| 合同分配 | 被分配的会签/审批/签订人员 | 通知有新的合同需要处理 |
| 会签完成 | 合同起草人 | 通知合同已完成会签，可定稿 |
| 审批通过 | 签订人员 | 通知合同已通过审批，可签订 |
| 审批否决 | 合同起草人 | 通知合同被否决，需修改后重新定稿 |

> 邮件通知需要在 **「系统设置」** 中配置SMTP服务器信息。

#### 4.5.4 合同导出

1. 在合同详情页面，点击 **「导出PDF」** 或 **「导出DOCX」** 按钮
2. 系统使用iText生成PDF文件，或生成DOCX文件
3. 浏览器自动下载导出的文件

## 第五章 管理员操作

### 5.1 用户管理

<!-- 【图片预留位置：用户管理页面完整截图】 -->
<!-- 请在此处插入用户管理页面的完整截图，包含待审核区域和用户列表 -->

#### 5.1.1 待审核用户

新用户注册后，会出现在待审核区域：

| 操作 | 按钮 | 说明 |

#### 5.1.2 用户列表

| 操作 | 按钮 | 说明 |
|------|------|------|

## 第六章 常见问题

### Q1: 启动时提示数据库连接失败怎么办？

**A:** 请确保Oracle数据库已启动。可以双击运行 `doc\start.bat` 启动数据库，等待数据库就绪后再启动Spring Boot应用。

### Q2: 浏览器无法访问 http://localhost:8080？

**A:** 请检查：
- Spring Boot应用是否已成功启动（控制台显示 "Started ContractApplication"）
- 端口8080是否被其他程序占用
- 防火墙是否阻止了本地连接

### Q3: 注册后为什么登录不了？

**A:** 本系统采用了**审核机制**。新用户注册后状态为"待审核"，需要管理员在 **「用户管理」→「待审核用户」** 区域中点击 **「通过」** 后才能登录。

### Q4: 我不是管理员，看不到某些菜单怎么办？

**A:** 这是正常的权限控制。侧边导航栏只显示你拥有权限的功能。如果你需要更多权限，请联系管理员为你分配相应的角色。

### Q5: AI智能起草功能无法使用？

**A:** 请检查：
- Ollama是否已安装并运行（命令行执行 `ollama list` 查看模型列表）
- qwen2:7b模型是否已下载（`ollama pull qwen2:7b`）
- 系统设置中AI配置是否正确（Ollama地址和模型名称）
- Ollama默认端口11434是否可访问

### Q6: 邮件通知没有收到？

**A:** 请检查：
- 系统设置中SMTP配置是否正确
- 发件人邮箱是否开启了SMTP服务
- 邮箱密码是否为授权码（非登录密码）
- 收件人邮箱是否在垃圾邮件中

### Q7: 审批否决后合同怎么办？

**A:** 审批否决后，合同会退回到定稿阶段。起草人可以在定稿页面查看审批否决的意见，根据意见修改合同内容后重新定稿，合同将再次进入审批流程。

### Q8: 电子签名如何使用？

**A:** 在签订合同页面，使用鼠标在签名画布上手写签名即可。签名会以图片形式保存到合同中。如需重新签名，点击"清除签名"按钮。

### Q9: 如何导出合同？

**A:** 在合同详情页面，点击"导出PDF"或"导出DOCX"按钮，系统会自动生成文件并下载到本地。

### Q10: admin账户可以被删除吗？

**A:** **不可以**。系统内置的admin账户受保护，删除操作会被阻止。这是为了防止系统中没有任何管理员的情况发生。

### Q11: 数据在哪里？如何备份？

**A:** 数据存储在Oracle数据库中。可以使用以下方式备份：
```bash
expdp scott/tiger@localhost:1521/freepdb1 directory=DATA_PUMP_DIR dumpfile=backup.dmp
```

### Q12: 如何查看历史意见？

**A:** 在合同操作的各个步骤（会签、定稿、审批、签订）中，都可以查看之前所有人的操作意见。选中合同后，历史意见区域会展示完整的流转记录。
