## 六、经验总结与反思

### 6.1 项目中遇到的主要问题及解决方案

| 问题 | 原因 | 解决方案 | 经验教训 |
|------|------|----------|----------|
| B/S架构迁移 | 从Swing桌面端迁移到Web端 | 采用Spring Boot + Thymeleaf渐进式重构 | B/S架构更适合企业级应用，部署维护成本低 |
| Oracle JDBC连接 | SID vs Service Name混淆 | 使用 `//host:port/service_name` 格式 | Oracle PDB连接必须用Service Name |
| 电子签名实现 | Web端手写签名 | 使用HTML5 Canvas + JavaScript | Canvas API功能强大，适合手写签名场景 |
| AI集成 | Ollama本地AI调用 | 通过HTTP API调用Ollama服务 | 本地AI保护数据隐私，适合企业内部使用 |
| 邮件通知配置 | SMTP配置灵活性问题 | 系统设置页面动态配置 | 关键配置应支持运行时修改，无需重启 |

### 6.2 如果重新做，会改进的地方

| 改进点 | 现状 | 改进方向 |
|--------|------|----------|
| 密码安全 | 明文存储 | BCrypt加密存储 |
| 单元测试 | 缺少自动化测试 | 引入JUnit + MockMvc编写测试用例 |
| 前后端分离 | Thymeleaf服务端渲染 | 可考虑Vue.js + RESTful API完全分离 |
| WebSocket | 待办任务轮询刷新 | 使用WebSocket实现实时推送 |
| 缓存优化 | 无缓存 | 引入Redis缓存热点数据 |
| 国际化 | 中文硬编码 | 使用ResourceBundle支持多语言 |
