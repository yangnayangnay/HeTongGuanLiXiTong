## 六、经验总结与反思

### 6.1 项目中遇到的主要问题及解决方案

| 问题 | 原因 | 解决方案 | 经验教训 |
|------|------|----------|----------|
| Swing按钮颜色渲染异常 | Windows外观下setOpaque不够 | 同时设置setContentAreaFilled(true) | Swing自定义UI需了解底层绘制机制 |
| Oracle JDBC URL格式 | SID vs Service Name混淆 | 使用 `//host:port/service_name` 格式 | Oracle PDB连接必须用Service Name |
| 数据库schema变更 | 后加status列导致旧数据不兼容 | 启动时自动ALTER TABLE迁移 | 向后兼容设计很重要 |
| 权限粒度控制 | 初期只做了菜单级别权限 | 增加了内容级别的权限控制 | 权限设计要从一开始就考虑多层 |

### 6.2 如果重新做，会改进的地方

| 改进点 | 现状 | 改进方向 |
|--------|------|----------|
| 密码安全 | 明文存储 | MD5/BCrypt加密存储 |
| 单元测试 | 缺少自动化测试 | 引入JUnit编写测试用例 |
| SQL注入防护 | 使用PreparedStatement（已做） | 可进一步引入MyBatis/Hibernate ORM |
| 附件上传功能 | 表已预留但功能未实现 | 完成文件上传和下载功能 |
| 数据导出 | 不支持 | 增加Excel/PDF导出功能 |
| 国际化 | 中文硬编码 | 使用ResourceBundle支持多语言 |
