# 合同管理系统 - 测试报告

## 一、测试概述

### 1.1 测试目的

验证合同管理系统的各项功能是否符合需求规格说明书的要求，确保系统在正常使用和异常情况下都能稳定运行。

### 1.2 测试范围

| 测试类别 | 测试内容 |
|----------|----------|
| 功能测试 | 全部12个功能点(A级需求) + 4个B级需求 + 2个C级需求 + 15个扩展需求 |
| 界面测试 | 所有Web页面的布局、交互、样式 |
| 权限测试 | RBAC权限控制（前端菜单 + 后端API验证） |
| 异常测试 | 边界条件和异常输入的处理 |
| 兼容性测试 | 浏览器兼容性（Chrome/Firefox/Edge） |

### 1.3 测试环境

| 项目 | 配置 |
|------|------|
| 操作系统 | Windows 10/11 |
| JDK版本 | 1.8+ |
| 应用服务器 | Spring Boot内嵌Tomcat (端口8080) |
| 数据库 | Oracle 26ai Free Release 23.26.0.0.0 |
| 浏览器 | Chrome 120+ / Firefox 120+ / Edge 120+ |
| AI服务 | Ollama + qwen2:7b (端口11434) |
| 测试日期 | 2026年6月18日 |
