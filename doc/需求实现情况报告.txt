一、架构说明
--------------------------------------------------------------------------------
当前采用架构: C/S架构（客户端/服务器模式）
  - 客户端: Java Swing桌面应用程序（GUI）
  - 服务端: Oracle 26ai Free 数据库
  - 通信方式: JDBC直连数据库
  - 部署方式: 用户需安装JRE环境运行JAR包

关于B/S架构的说明:
  B/S架构（浏览器/服务器）是指通过Web浏览器访问的应用程序，
  通常技术栈为Spring Boot/Spring MVC + Vue.js/React等前端框架。

  本项目选择C/S架构的原因:
  1. 课程设计原始要求基于Java Swing GUI开发
  2. C/S架构提供更丰富的桌面交互体验（如手写签名板、日历选择器等）
  3. 无需部署Web服务器，简化运维复杂度
  4. 数据安全性更高（数据不经过HTTP传输层）

  如需迁移至B/S架构的建议:
  - 后端保持Java不变，改为Spring Boot RESTful API
  - 前端改用Vue.js + Element UI替代Swing组件
  - 数据库保持Oracle不变
  - 工作量估计: 需要重写约70%的前端代码
