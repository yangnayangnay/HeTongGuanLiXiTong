# 合同管理系统 - 系统架构说明

## 一、架构概述

本系统采用 **B/S（Browser/Server）架构**，基于 Spring Boot 2.7.18 + Thymeleaf + Oracle Database 构建。用户通过浏览器访问系统，无需安装客户端。

### 1.1 架构特点

| 特点 | 说明 |
|------|------|
| 零客户端部署 | 用户只需浏览器即可访问，无需安装任何客户端软件 |
| 统一部署维护 | 应用部署在服务器端，更新只需重启服务，所有用户即时生效 |
| 跨平台访问 | 支持Windows/Mac/Linux等任何操作系统的浏览器 |
| 多用户并发 | Spring Boot内嵌Tomcat支持多用户同时访问 |

### 1.2 系统访问方式

- **访问地址**：http://localhost:8080
- **推荐浏览器**：Chrome 120+ / Firefox 120+ / Edge 120+
- **网络要求**：客户端需能访问服务器8080端口

### 2.2 请求处理流程

```
浏览器请求
    │
    ├─ 页面请求 (GET /draft)
    │      │
    │      ▼
    │  PageController
    │      │
    │      ▼
    │  Service → DAO → Oracle
    │      │
    │      ▼
    │  Thymeleaf渲染HTML → 返回浏览器
    │
    └─ API请求 (POST /api/contract/draft)
           │
           ▼
       ApiController (权限验证)
           │
           ▼
       Service → DAO → Oracle
           │
           ▼
       返回JSON结果 → 浏览器JavaScript处理
```

## 三、核心组件说明

### 3.1 Spring Boot框架

| 组件 | 说明 |
|------|------|
| ContractApplication | Spring Boot启动入口，@SpringBootApplication |
| DataInitializer | @PostConstruct自动初始化数据库 |
| application.properties | 数据源、Thymeleaf、端口等配置 |
| 内嵌Tomcat | 默认端口8080，无需外部Web服务器 |

### 3.2 Thymeleaf模板引擎

| 特性 | 说明 |
|------|------|
| 服务端渲染 | HTML在服务器端生成，SEO友好 |
| 自然模板 | 可直接在浏览器中打开预览 |
| 与Spring Boot集成 | 自动配置，无需额外设置 |
| 表达式语言 | th:text, th:each, th:if 等动态渲染 |

### 3.3 前端技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Bootstrap | 4.6.2 | 响应式布局、UI组件 |
| Font Awesome | 5.15.4 | 图标库 |
| HTML5 Canvas | - | 电子签名手写画布 |
| JavaScript | ES6+ | 前端交互逻辑 |
| jQuery | 3.x | AJAX请求、DOM操作 |

### 3.4 外部服务集成

| 服务 | 地址 | 用途 |
|------|------|------|
| Ollama AI | http://localhost:11434 | AI智能起草（qwen2:7b模型） |
| SMTP邮件 | 配置的SMTP服务器 | 邮件通知 |
| Oracle DB | localhost:1521/freepdb1 | 数据持久化 |

## 四、安全架构

### 4.1 认证机制

```
用户登录 → Session管理 → 后续请求携带Session ID → 服务端验证
```

### 4.2 授权机制

```
请求到达Controller
    │
    ├─ 前端权限控制：菜单/按钮根据用户角色动态显示
    │
    └─ 后端权限验证：ApiController验证用户是否拥有对应功能权限
           │
           ├─ 有权限 → 执行业务逻辑
           └─ 无权限 → 返回权限不足错误
```

### 4.3 数据安全

| 措施 | 说明 |
|------|------|
| PreparedStatement | 防止SQL注入 |
| 内容权限控制 | 合同正文仅管理员和起草人可查看 |
| 防重复提交 | 按钮锁定机制 |
| 管理员自保护 | 不能取消自身管理员权限 |
| AI本地部署 | Ollama本地运行，数据不出本机 |

## 五、部署架构

### 5.1 单机部署（当前方案）

```
┌─────────────────────────────────────────┐
│              服务器 (localhost)           │
│                                         │
│  ┌─────────────┐  ┌─────────────────┐  │
│  │ Oracle DB   │  │ Spring Boot App │  │
│  │ :1521       │  │ :8080           │  │
│  └─────────────┘  └─────────────────┘  │
│                                         │
│  ┌─────────────┐                        │
│  │ Ollama AI   │                        │
│  │ :11434      │                        │
│  └─────────────┘                        │
└─────────────────────────────────────────┘
         │
         ▼
    浏览器访问 http://localhost:8080
```

### 5.2 启动流程

1. 启动Oracle数据库（`doc/start.bat`）
2. 启动Ollama AI服务（可选，`ollama serve`）
3. 运行 `ContractApplication.main()`
4. 浏览器访问 http://localhost:8080
